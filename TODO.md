# Velorah acceptance criteria

- [ ] Fullscreen background video uses the supplied MP4 URL with `autoPlay`, `loop`, `muted`, and `playsInline`, positioned absolute inset-0, full-size, object-cover, z-0.
- [ ] Google Fonts import Instrument Serif for display and Inter weights 400/500 for body; CSS variables define `--font-display` and `--font-body`, body uses the body variable, and headings use Instrument Serif.
- [ ] Dark HSL theme uses deep navy background, white foreground, muted gray text, white primary, near-black secondary/muted/accent, and dark border/input values.
- [ ] Navigation is responsive and glassmorphic: Velorah® wordmark, desktop links Home/Studio/About/Journal/Reach Us, and Begin Journey CTA; desktop links are hidden on mobile.
- [ ] Hero is vertically centered with the exact headline, exact supporting copy, responsive display sizing, muted emphasis on “dreams” and “through the silence.”, and a prominent Begin Journey CTA.
- [ ] Liquid-glass style includes translucent luminosity background, 4px backdrop blur, inset highlight, overflow clipping, and masked gradient pseudo-element border.
- [ ] Fade-rise animation is applied to headline, subtext, and hero CTA with the specified 0.8s timing and 0.2s staggered delays.
- [ ] Layout contains no decorative blobs, radial gradients, or overlays; the video provides visual depth.
